# Implementer notes for issue #4

## Design
Add a dedicated inline pattern for schemes without `//` (`tel:`, `sms:`, `callto:`, `facetime:`, `skype:`),
reusing `AutolinkInlineProcessor`, registered above autolink and automail (priority 125) so that a `skype:` link
with an `@` is not taken for an e-mail address. Code spans are handled earlier by the backtick processor.

## Implementation attempt summary
Added `OPAQUE_LINK_RE` and registered `opaquelink` at priority 125. Tests cover a list, emphasis, a code span and a
`skype:` link containing `@`. The full suite passes.
