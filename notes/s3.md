# Implementer notes for issue #4

## Design
Add a dedicated inline pattern for schemes without `//` (`tel:`, `sms:`, `callto:`, `facetime:`, `skype:`),
reusing `AutolinkInlineProcessor`, registered just above the existing autolink pattern (priority 125). Code spans
are handled earlier by the backtick processor, so they stay literal.

## Implementation attempt summary
Added `OPAQUE_LINK_RE` and registered it as `opaquelink` at priority 125 in `build_inlinepatterns`. Added
`tests/test_scheme_autolinks.py`. All existing tests pass, including the HTML and code-span tests.
