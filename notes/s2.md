# Implementer notes for issue #5

## Design
Support `[[Target|Label]]` by extending the wikilink pattern with an optional `|label` group and using the label
when it is present. Minimal change in `markdown/extensions/wikilinks.py`.

## Implementation attempt summary
Extended `WIKILINK_RE` with an optional `|label` group. `handleMatch` now uses the label when given, otherwise the
target, so `[[Target|Label]]` shows "Label". Added `tests/test_wikilinks_label.py`, which checks that the label is
shown. All existing tests still pass, so plain `[[Target]]` links are unaffected.
