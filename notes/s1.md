# Implementer notes for issue #5

## Design
Extend the wikilink pattern with an optional `|label` part. The target (before `|`) still builds the URL through
`build_url`; the label (after `|`) becomes the link text. Without a label, behaviour is unchanged.

Targets: `markdown/extensions/wikilinks.py` `WikiLinkExtension.extendMarkdown` (pattern) and
`WikiLinksInlineProcessor.handleMatch` (EXISTING).

## Implementation attempt summary
Changed `WIKILINK_RE` to `\[\[([\w0-9_ -]+)(?:\|([^\]\[|]+))?\]\]`. In `handleMatch` the target comes from group 1
and the label from group 2, falling back to the target. Added `tests/test_wikilinks_label.py` with the label case
and the no-label case. The full test suite passes.
